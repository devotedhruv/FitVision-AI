# Real-device checklist

For each device record model alias, Android version, RAM class, build mode and ambient conditions. Exercise runs cover bright/normal/dim/backlit light; front/side/offset placement; near/supported/far framing; slow/normal/fast-controlled/partial/hold; pause and landmark loss. Record camera FPS, engine median/p95/p99, feedback latency, rep labels and crashes.

Running checks cover fresh/denied/revoked permission, measured route, stationary drift, pause/resume in a new location, weak/lost GPS, screen off, background/foreground, notification actions, connectivity loss, force-stop observation and finish cleanup. Battery observations require initial/final percentage, duration, screen/map/network state and thermal notes. Never report a pass without the recorded observation.
