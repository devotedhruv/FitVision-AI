# Threshold configuration

Defaults are calibration starting points, not universal form standards.

| Setting | Default |
|---|---:|
| Required landmark confidence | 0.60 |
| EMA alpha | 0.35 |
| Tracking reset gap | 750 ms |
| Stable frames | 3 |
| Rep duration | 500 ms–10 s |
| Feedback cooldown | 1.5 s |
| Squat standing / descend / bottom / ascend | 160 / 155 / 100 / 105° |
| Curl extended / flex / contracted / extend | 155 / 145 / 55 / 65° |
| Push-up top / descend / bottom / ascend | 155 / 145 / 90 / 100° |
| Push-up alignment | 160° minimum |

Calibrate with consented, diverse recordings across body proportions, clothing,
lighting, devices and camera distances. Change one typed config value at a
time, rerun fixtures, and validate false-positive and false-negative rates.
