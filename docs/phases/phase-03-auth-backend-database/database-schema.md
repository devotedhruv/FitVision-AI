# Database Schema

- `profiles`: one row per Supabase Auth UUID.
- `exercise_definitions`: versioned read-only catalogue; five seeded exercises.
- `workout_sessions`: belongs to a profile and exercise definition; unique
  `(user_id, client_session_id)` makes offline retries idempotent.
- `rep_events`: belongs to a workout and cascades on workout deletion; unique
  `(workout_session_id, rep_number)`.
- `running_sessions`: belongs to a profile; unique
  `(user_id, client_session_id)`.
- `running_points`: ordered children of a run and cascades on run deletion;
  unique `(running_session_id, sequence_number)`.

Checks enforce coordinate ranges, non-negative measurements and counts,
0–100 form scores, timestamp ordering, and consistent rep totals. Ownership,
foreign-key, slug, and start-time columns are indexed. UUIDs are generated by
the application, so no PostgreSQL extension is required.

The seed marks squat, biceps curl, and push-up as MVP entries in their
instruction metadata. Lunge and plank are active extended-scope definitions.
