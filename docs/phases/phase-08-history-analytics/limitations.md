# Limitations

- The app has no reliable numeric form score, so score charts/trends remain unavailable rather than fabricated.
- The accessible custom-painted chart currently shows exercise rep totals; full daily/weekly/monthly multi-series charts are deferred.
- Custom date selection UI exposes typed support but currently uses preset dropdowns rather than calendar pickers.
- Backend timezone validation exists, while its SQL calendar grouping endpoints remain summary-oriented.
- Remote refresh/merge is not implemented; fully local analytics prevent double counting unsynced sessions.
