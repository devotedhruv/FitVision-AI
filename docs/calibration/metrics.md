# Evaluation metrics

`evaluation_metrics.py` calculates exact count agreement, mean absolute count error, over/under-count rate, binary precision/recall/F1 with support, and median/p95/p99 latency. Planned device evaluation additionally measures duplicate/hold false positives, per-rule confusion matrices, feedback latency, effective FPS/drops, GPS absolute/percentage error, stationary drift, pause jump, crashes and battery observations. Every report labels sample size and measured versus inferred/not tested.
